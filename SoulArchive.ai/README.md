# SoulArchive.AI

AIとの対話を「魂の記録」として保存するための、ミニマルなブラウザ拡張機能です。

## 概要

SoulArchive.AIは、ChatGPT、Gemini、ClaudeといったAIチャットサービスの会話ログを、ワンクリックで清潔なテキストファイル（.txt）としてエクスポートします。
エンジニアではない「創作マン」や「文系層」のユーザーが、AIとの大切な対話を読み物や資料として美しく残せることを目指して開発されました。

## 特徴

- **シンプル設計**: 複雑な設定は不要。「Export」ボタンを押すだけで即座に保存されます。
- **構造の維持**: Markdownの見出しやリスト構造を適切に解釈し、読みやすいレイアウトで出力します。
- **プライバシー重視**: 対話データは一切外部サーバーに送信されません。すべての処理はあなたのブラウザ内（ローカル環境）で完結します。
- **高解像度対応**: モダンなディスプレイ環境でも美しく表示されるアイコン設計。

## ディレクトリ構成

- `manifest.json`: 拡張機能の定義ファイル
- `content.js`: 画面上のテキスト抽出・整形・ダウンロードロジック
- `popup.html` / `popup.js`: 保存ボタンを表示するUIおよび制御
- `icons/`: 各解像度（16px, 32px, 48px, 128px）のアプリ用アイコン
- `assets/`: UIパーツ用リソース（download.svg等）

## 使い方

1. Chrome ウェブストアから本拡張機能をインストールします。
2. 対応しているAIチャットサービス（ChatGPT等）のページを開きます。
3. 拡張機能のアイコンをクリックし、表示された「Export」ボタンを押してください。
4. 会話ログが `.txt` ファイルとしてダウンロードされます。
